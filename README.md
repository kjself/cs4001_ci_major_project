## Major Project: Automated Quality Control (QA) Dashboard
This repository holds the work of Team RKM for Professor Nair's CS4001 class. 
### Problem Description
While neuroimaging pipelines such as DeepPrep generate detailed quality assurance reports, reviewing them manually across many subjects is slow and can lead to missed problems. Important indicators of scan quality, such as carpet plots and Temporal Signal-to-Noise Ratio maps, are often embedded within HTML reports that must be individually checked. This project addresses that limitation by developing an automated Quality Assurance dashboard that parses DeepPrep HTML reports and aggregates key metrics across more than 100 subjects. By programmatically extracting and summarizing these measures, the system will flag scans that fall outside acceptable thresholds and provide a centralized overview of dataset quality. The result will support more reliable preprocessing workflows and strengthen data validation practices in large-scale neuroimaging studies.
