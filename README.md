## Major Project: Automated Quality Control (QA) Dashboard
This repository holds the work of Team RKM for Professor Nair's CS4001 class. 
### Problem Description
Utilizing DeepPrep, our study will use high-resolution 3T MRI scans to examine the brain’s physical structure, wiring, and activity levels. By comparing individuals with temporal lobe epilepsy to a group of healthy participants, the research team aims to identify the specific differences between these two groups. To ensure accuracy, the project implements a standardized system (DeepPrep within a BIDS framework) to organize and clean the data. This consistent approach allows for reliable comparisons across different subjects and scanning sessions. The researchers will then extract quantitative data from these scans and apply statistical tools and machine learning techniques to identify patterns. This includes using methods like Principal Component Analysis to simplify complex data sets into their most important features. The ultimate goal of this work is to define group-level variances and discover potential biomarkers. These biomarkers act as biological signatures that can help experts better understand the pathology of epilepsy and how it differs from a healthy brain.
